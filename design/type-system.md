# Types

Six types. Hitting a type you beat does a bit more damage, and the announcer shouts the callout.

| Type | Beats | Callout |
|---|---|---|
| Khaki | Jalsa, Khandaan | "CONTAINER'D!" / "EXILED!" |
| Qanoon | Khandaan, Mic | "DISQUALIFIED!" / "CONTEMPT!" |
| Jor-Tor | Khaki, Qanoon | "EXTENSION!" / "NRO!" |
| Mic | Khaki, Jor-Tor | "TRENDING!" / "LEAKED!" |
| Jalsa | Qanoon, Mic | "RESTORED!" / "FINAL CALL!" |
| Khandaan | Jalsa, Jor-Tor | "ZINDA HAI!" / "FAMILY FIRST!" |

Health bar is **Awaam**. Super meter is **Political Capital**. A time-out win is a **Form 47** win.
